# Instrument Tech Fundamentals

A phone-friendly, 11-module training course for entry-level oil field instrument technicians. Each module has a lesson, a hands-on tool, and a quiz. Trainees type their name and text their results back to their trainer.

Lesson content is based on *Lessons in Industrial Instrumentation* by Tony R. Kuphaldt (v2.33), licensed under Creative Commons Attribution 4.0.
