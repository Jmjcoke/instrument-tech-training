# Instrument Tech Fundamentals

A phone-friendly, 11-module training course for entry-level oil field instrument technicians. Each module has a lesson, a hands-on tool, and a quiz. Trainees type their name and text their results back to their trainer.

Lesson content is based on *Lessons in Industrial Instrumentation* by Tony R. Kuphaldt (v2.33), licensed under Creative Commons Attribution 4.0.

## Two versions, one course

- `index.html` is the phone version: one card at a time, built for thumbs.
- `desktop.html` is the desktop workbench: a big interactive stage with hover call-outs, zoom and pan, the lesson text and "try it yourself" controls beside it, a lesson strip along the bottom, and Lessons, Tools, Textbook and Settings pages.
- `course.js` holds everything both versions share: the module text, figures, interactive figures, hands-on tools and quiz questions. Edit course content there and both versions pick it up.

Quiz scores and the trainee name are shared between the two versions in the same browser.
